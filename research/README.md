# 業績ファイルの書き方

業績は **1件につき1ファイル** で，`research/<年>/` に置きます．
ファイルを追加・修正して GitHub に push すると，数分でサイトに反映されます（HTML を書く必要はありません）．

```
research/
├─ 2024/
│   ├─ paper-202407.md     論文・会議発表など
│   └─ paper-202445.md
├─ 2025/
│   └─ award-51.md         受賞
├─ _template/              ひな形（コピーして使う．サイトには表示されない）
└─ index.json              全業績の一覧（GitHub Pages が自動で作る．編集しない）
```

## 追加のしかた

1. `_template/` から種類に合うひな形をコピーし，`research/<年>/` に置く
2. ファイル名を `<種類>-<番号>.md` にする（例 `paper-202601.md`）
3. 中身の `""` の間に値を書く
4. push する

| 種類 | ファイル名 | ひな形 |
|---|---|---|
| 論文・会議発表・解説など | `paper-<番号>.md` | `_template/paper-000000.md` |
| 特許 | `patent-<番号>.md` | `_template/patent-0.md` |
| 受賞 | `award-<番号>.md` | `_template/award-0.md` |
| 取材記事・TV など | `media-<番号>.md` | `_template/media-0.md` |

- **ファイル名はサイト全体で重複しないようにしてください**（個別ページの URL になります．例 `research/2024/paper-202407.html`）．
- 年のフォルダは整理用です．一覧の年タブは中身の「日付」で決まります（特許は公開日，無ければ出願日）．

## 書き方のルール

```
---
タイトル: "LIBRA-I：小径孔を通過可能な内部調査用軽量長尺多関節アーム"
種別: "論文"
日付: "2024-03-22"
PDF: ""
---
```

- 先頭と最後の `---` は消さないでください．
- 1行に「項目名: "値"」を1つずつ書きます．**値は必ず `"` で囲んでください**（`:` などの記号が入っても壊れないように）．
- 値の中に `"` を書きたいときは `\"` と書きます．
- 空欄（`""`）の項目は，個別ページの表に表示されません．
- 日付は `"2024-03-22"` の形（月までなら `"2024-03"`）．
- 文字コードは UTF-8（VS Code やメモ帳で普通に保存すれば UTF-8 になります）．

## 項目

### 論文・発表（paper-）

| 項目 | 書き方 |
|---|---|
| タイトル | |
| 種別 | `論文` / `国際会議発表` / `国内会議発表` / `解説・総説` / `著作` / `その他` |
| 査読 | `査読あり` / `査読なし` |
| 著者 | 例 `後藤 優斗, 遠藤 玄` |
| 言語 | `日本語` / `英語` |
| 掲載誌 | 学術誌名・会議名 |
| 巻号ページ | 例 `Vol. 42 No. 2 pp. 168-176`，講演番号のみなら `1A1-L07` |
| 日付 | 出版日（論文）または発表日（会議） |
| DOI | `10.7210/jrsj.42.168` の形．あれば「論文を読む」ボタンが出る |
| URL | DOI が無いときの論文ページ（IEEE Xplore など）．あれば「論文を読む」ボタンになる |
| PDF | T2R2 などの PDF の URL．あればページ最下部に「PDFをダウンロード」ボタンが出る |

### 特許（patent-）

| 項目 | 書き方 |
|---|---|
| タイトル | 発明の名称 |
| 状態 | `登録` / `公開` など（一覧の小ラベルになる） |
| 発明者 / 出願人 | |
| 出願番号 / 出願日 / 公開番号 / 公開日 / 登録番号 / 登録日 | |

**公開前の特許（公開番号が無いもの）は載せないでください．**

### 受賞（award-）

| 項目 | 書き方 |
|---|---|
| タイトル | 賞の名前 |
| 受賞者 | |
| 日付 | 受賞日 |
| 表彰機関 | |
| 関連業績 | 対象の論文のファイル名の番号（例 `202407`）．複数なら `;` で区切る．特許などは `patent-40` のように書く |
| URL | 学会の受賞者一覧ページなど |

関連業績を書くと，**論文側のページの「受賞」欄にも自動で表示**されます（論文側に書く必要はありません）．

### 取材記事・TV など（media-）

| 項目 | 書き方 |
|---|---|
| タイトル | 記事・番組のタイトル |
| 種別 | `TV` / `全国紙` / `専門紙` / `Webメディア` など（一覧の小ラベルになる） |
| 媒体 | 新聞名・番組名など |
| 日付 | 掲載日・放送日 |
| URL | 記事のページ．あれば「記事を見る」ボタンが出る |

## 項目を増やしたいとき

新しい項目名を使う場合は，`research/index.json` の `keys` にも同じ名前を追加してください（追加しないと一覧データに入りません）．
表への表示のしかたは `js_includes/data.js` の `BUILDERS` で決めています．

## 手元で確認する

リポジトリのフォルダで `python tools/preview.py` を実行し，表示された URL をブラウザで開きます．
ファイルを保存してブラウザを再読み込みすれば反映されます．書き方の誤りはこのコマンドの画面に `[警告]` として出ます．
